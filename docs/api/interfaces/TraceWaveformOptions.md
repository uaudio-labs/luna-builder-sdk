# Interface: TraceWaveformOptions

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="axis"></a> `axis?` | `readonly` | `number` | Distance each outline sits beyond the zero line, so silence draws a thin axis line rather than vanishing; default 0.5, as LUNA draws it. |
| <a id="columnwidth"></a> `columnWidth?` | `readonly` | `number` | Width of one column in the target's units; default 1. Use `1 / devicePixelRatio` for device-pixel columns. |
