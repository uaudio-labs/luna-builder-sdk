# Interface: PresetSelectionOptions

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="limit"></a> `limit?` | `number` | Most rows in `presets`. Default: all of them. |
| <a id="maxrecommendations"></a> `maxRecommendations?` | `number` | Most rows in `recommendations`. Default 5. |
| <a id="querydelayms"></a> `queryDelayMs?` | `number` | Quiet time after a change before the list is queried, in ms. Default 100. |
| <a id="recommend"></a> `recommend?` | `boolean` | Ask UA Assistant for recommendations. Default true. |
| <a id="recommenddelayms"></a> `recommendDelayMs?` | `number` | Quiet time after a change before recommendations are asked for, in ms. Default 300. |
