# Interface: PluginWindow

One plugin editor window open in LUNA, from [Gui.pluginWindows](../classes/Gui.md#pluginwindows).

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="channeluid"></a> `channelUid` | `string` | The track or bus uid. |
| <a id="sessionuid"></a> `sessionUid` | `string` | - |
| <a id="slot"></a> `slot` | `string` | The insert slot, for example `effect_0`. |
