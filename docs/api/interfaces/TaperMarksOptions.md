# Interface: TaperMarksOptions

Options for [Taper.marks](../classes/Taper.md#marks).

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="compact"></a> `compact?` | `boolean` | The short set, for a fader too short for the full one. LUNA switches to it when the 0 dB and −6 dB marks would be 10 px apart or less (20 px for `API`). |
