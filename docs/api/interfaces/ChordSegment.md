# Interface: ChordSegment

One detected chord over a stretch of the source.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="end"></a> `end` | `number` | - |
| <a id="name"></a> `name` | `string` | The detector's chord label, verbatim (`N` is its "no chord"). |
| <a id="start"></a> `start` | `number` | Seconds from the source's start. |
