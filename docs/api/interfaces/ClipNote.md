# Interface: ClipNote

One note for [Clip.addNotes](../classes/Clip.md#addnotes). `tick` is relative to the clip start.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="channel"></a> `channel?` | `number` | MIDI channel, 0-15. Default 0. |
| <a id="lengthticks"></a> `lengthTicks` | `number` | - |
| <a id="pitch"></a> `pitch` | `number` | - |
| <a id="tick"></a> `tick` | `number` | - |
| <a id="velocity"></a> `velocity?` | `number` | Note-on velocity, 1-127. Default 100. |
