# Function: midiByte()

```ts
function midiByte(
   value, 
   what, 
   min): number;
```

A 7-bit MIDI value, or `out_of_range`. `min` is 1 for a velocity that must sound.

## Parameters

| Parameter | Type | Default value |
| ------ | ------ | ------ |
| `value` | `unknown` | `undefined` |
| `what` | `string` | `undefined` |
| `min` | `number` | `0` |

## Returns

`number`
