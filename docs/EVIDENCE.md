# Engine behaviour: measured facts

Numbered facts about how the UANet engines behave. Code comments cite them as
"fact N"; `Luna.MockEngine` reproduces them; the live lane re-verifies them.

Status meanings:
- **verified**: seen in engine source, protocol docs, or a wire capture.
- **production**: not in the docs, but LUNA's own GUI or the shipping LUNA SDK
  relies on it, so it holds for the LUNA versions they ship with.
- **unverified**: reasoned or borrowed; needs a live check before code depends on it.
- **verified elsewhere**: measured against a live LUNA by a sibling client (the source
  names which, and on which build), but not yet re-measured by this SDK's own live lane.
  Stronger than *unverified*, weaker than *verified*; the open checks below list what to
  re-measure.
- **observed**: seen by eye in LUNA (how a page looks or behaves), with nothing on the wire to
  capture; the source names who saw it, where, and on which platform.
