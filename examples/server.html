Server

An Add On reaches no server but LUNA on this computer unless its manifest lists the server in network and the user allows it (docs/MANIFEST.md, "Network"). This page's entry lists musicbrainz.org, a public music database with no API key, and looks songs up there. LUNA asks the first time it opens; allow or remove it later in Settings > Add Ons > SERVERS, which reloads the page.
