Folder browser

Walks the disk as LUNA sees it with luna.gui.listFiles(path): the entries directly inside a folder, hidden ones left out, sorted by name. LUNA lists only folders you gave it, and the folders inside them: pick one with LUNA's dialog (luna.gui.chooseFolders()) or drop one on this page. LUNA remembers them, the blessed folders, until you remove them in Settings > Add Ons > FOLDERS, so a typed path works inside a folder you gave it before. Click a folder to open it. Import copies an audio file into the open session with session.importPath(), then puts it on a new track at the playhead (newTrack() and insertClip(), one undo entry). Or drag an audio file onto LUNA's timeline: the drag carries its path, and LUNA places it on the lane or a new track where you drop it. These are paths for the engine; the page cannot read them (docs/FILES.md).
