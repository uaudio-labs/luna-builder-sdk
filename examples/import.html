Import and record

Pick or drop a file and watch it upload to LUNA in chunks, appear in the session's source list, and go onto the timeline as a clip. The upload is session.uploadFile(), which sends base64 chunks through the engine's begin/transfer/end phases and reports progress after each one (fact 42). This is the File route: it works in LUNA and a browser alike. A path from luna.gui.chooseFiles() takes session.importPath(path) instead, which the page cannot read but the engine copies without the upload (docs/FILES.md).

The clip's span is computed through the tempo map with timeline.tickAtSeconds(), so the source plays unstretched wherever it lands.
