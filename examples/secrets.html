Secrets

An API key belongs in luna.secrets, not in web storage (docs/MANIFEST.md, "Secrets"). Inside LUNA it goes to the OS keychain, kept for this install of the Add On and deleted when it is removed or updated; in a browser it lasts until reload. Install the examples and open this page from both "Secrets" Add Ons: they share this file but have different ids, so neither reads the other's key.
