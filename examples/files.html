Connecting…

A user's file reaches an Add On by one of two routes (docs/FILES.md). The File route gives the page File objects it can decode, and session.uploadFile() copies them into the session. The path route gives absolute paths the page cannot read; session.importPath() has the engine copy them. Try each panel and read the log: every event the page sees is written there.

Log

Browses the blessed folders, the folders you let every Add On read, like a Finder window. The sidebar is luna.gui.blessedFolders; LUNA lists them in Settings > Add Ons > FOLDERS. Add Folder… picks one with LUNA's dialog (chooseFolders()), which blesses it; ✕ beside a blessed folder, clicked twice, removes it (removeBlessedFolder()). Each folder is listed with luna.gui.listFiles(path). Double-click a folder to open it, or open its triangle in the sidebar to see the folders inside it. Import copies an audio file into the open session (session.importPath()) and puts it on a new track at the playhead, in one undo entry; or drag it onto LUNA's timeline. A folder that was moved, is on a drive that is not connected, or is no longer blessed shows as not available.
