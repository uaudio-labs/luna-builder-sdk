File routes

A user's file reaches an Add On by one of two routes (docs/FILES.md). The File route gives the page File objects it can decode, and session.uploadFile() copies them into the session. The path route gives absolute paths the page cannot read; session.importPath() has the engine copy them. Try each panel and read the log: every event the page sees is written there.
